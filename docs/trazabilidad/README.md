# Trazabilidad del trabajo

Esta carpeta recoge los prompts relevantes, decisiones y resultados de cada sesión de trabajo del frontend de administración de SICOL.

Objetivo:

- Mantener control de qué se pidió, qué se implementó y qué quedó pendiente.
- Separar la memoria funcional del proyecto de la conversación puntual con Codex.
- Facilitar commits, revisiones y handoffs posteriores.

Convención propuesta:

- Un archivo por sesión con fecha y tema: `YYYY-MM-DD-tema.md`.
- Cada sesión incluye entradas del usuario, salidas/resumen de Codex, cambios realizados, validación y próximos pasos.
