Limpieza de procesos cargados

Restablece el entorno eliminando todos los procesos selectivos y sus datos operativos dependientes.

Datos que se eliminan:
  • Todos los procesos selectivos
  • Todos los ejercicios asociados
  • Personas opositoras convocadas y llamamientos
  • Asistencias registradas
  • Asignaciones de colaboradores a exámenes
  • Historial de importaciones e informes generados
Datos que se conservan intactos:
  • Colaboradores y perfiles de colaboración
  • Personas opositoras del catálogo base
  • Sedes, centros y aulas
  • Catálogos maestros (Cuerpos, Tipos de acceso, OEPs)
  • Usuarios de aplicación y permisos

Recarga de datos de prueba

Atajos directos para volver a poblar el sistema tras realizar una limpieza.

Importar convocatorias desde Datamart Sincroniza convocatorias oficiales, cuerpos y fechas de examen desde SIRHUS/Datamart.
Importar opositores y aulas Carga ficheros SIRHUS y CARONTE para asociar aspirantes y distribución de aulas.
Importar colaboradores Carga personal voluntario para asignaciones a tribunales y sedes de examen.
